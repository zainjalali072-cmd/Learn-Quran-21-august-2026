# Project Editing Rules

## Core Rule: Incremental Changes & Strict Data Preservation

1. **Preserve All Existing Content & Functionality**:
   - Never remove, overwrite, reset, or modify existing content, settings, sections, features, data, or functionality unless explicitly instructed to do so.
   - All Admin Panel data, articles, categories, and custom configurations must remain intact across edits.

2. **Targeted Edits Only**:
   - Limit changes strictly to the specific section, feature, or component requested.
   - Do not alter unrelated pages, components, styles, or logic.
   - Treat every prompt as an incremental modification, never a full reset or rebuild.

3. **Explicit Confirmation for Destructive Actions**:
   - Only delete, replace, or redesign elements if explicitly requested (e.g., "delete this section", "remove this feature").
   - Ask for clarification if a request is ambiguous and could potentially affect existing content or settings.
